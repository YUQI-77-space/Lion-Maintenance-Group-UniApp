# Team 首页 SVG 图标重绘

## 已实现

按用户要求手写九个 SVG，资源位于 `miniprogram/assets/icons/team/`。统一 48×48 viewBox、2.6 单位描边、圆角端点和品牌蓝 `#0369D7`，保留首页原有 80rpx 图标展示尺寸。

| 板块 | 图形语义 |
| --- | --- |
| 值班表／值班管理 | 排班日历与勾选 |
| 维修任务／维修任务管理 | 工单与扳手 |
| 志愿活动／志愿活动管理 | 手托爱心 |
| 维修手册 | 打开的工具书 |
| EWA 管理 | 工作量统计柱形图与趋势 |
| 组员管理 | 双人轮廓 |

管理版仅叠加同款右下角齿轮；前三组普通版与管理版主体几何完全相同。齿轮下有白色留白以避免线条交叠。

通过 `iconManager` 新增 `team_cover_*` 独立名称，仅首页使用；不替换其他页面的旧名称。首页每个入口保留原图标路径，SVG 加载失败时回退一次，权限、导航和点击范围未改变。

设计依据为知识库 Design 的 01（线性图标、同等粗细、品牌色）、02（功能入口）及 Token。UI/UX Skill 定向检索未获得适用的图标一致性结果，实际采用项目规范和 Skill 的线条一致性通用规则，没有引用外部图标库。

## 实际验证与限制

L0 已核对首页配置、图标管理器及其他图标调用点。L1 检查九个 SVG 均能解析，前三组主体一致；首次主体比较误包含 XML 节点尾部的格式空白，排除尾部格式空白后通过。两个修改的 JS 文件通过 `node --check`；本地执行实际首页配置和图标管理器，确认九个路径均存在、失败回退不会循环。

使用 Chrome headless 对 SVG 预览页生成 PNG 并人工查看，包含放大展示和 40px 参考尺寸。预览不包含真实微信运行环境。尚未进行微信开发者工具／真机 SVG 兼容性和回退资源的设备验收；回退使用此前已存在的媒体配置。未运行全量测试或构建，未新增依赖。

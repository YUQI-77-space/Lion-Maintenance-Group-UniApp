# 统一加载动画全量替换

创建日期：2026-10-25。

## 同日配色调整

按用户最新要求，统一加载组件由品牌蓝改为黑色 `#000000`，投影同步改为黑色弱阴影；所有已接入场景同步生效，动画节奏与交互逻辑不变。下方品牌蓝的实际渲染验证是本次调色前的记录，不代表调色后的验收。此次只改颜色，已检查公共样式及加载回归测试，未重新进行真机或模拟器视觉验收。

## 实际改动

- 按用户提供的双方块参考实现原生 WXML／WXSS 动画：单程 0.5 秒、第二块延迟 0.15 秒、上浮、缩放及 X 轴翻转。采用品牌蓝 Token 和弱阴影，保留 small／default／large、customClass 接口，增加静态及反白表现；页面隐藏暂停动画。
- 原有三圆点及旋转 loading 图形、相关旧样式已移除。初始化、分页、按钮提交、组员资料、值班表及设置进度、头像、图片与首页媒体等待均复用新组件。图片继续独立完成／失败，不增加人为等待。
- 新增 `utils/loading.js` 与 `loading-overlay`，显式迁移 16 个文件的系统 showLoading／hideLoading 调用；30 个注册页面均挂载弹层。保留业务文案、mask、success／complete 回调和按钮防重锁，不修改微信全局 API。弹层归属当前页，页面隐藏或组件卸载清理并退订。
- 7 个原生下拉刷新页面改用 scroll-view；其余已有 scroll-view 刷新区也关闭默认转圈并使用统一刷新槽。新 `pageRefresh` Behavior 将滚动、触底及刷新分发回原有页面方法，完成／失败后复位；首页滚动导航及相册分页继续使用原逻辑，EWA 回顶改为滚动容器回顶。
- 更新稳定设计规范。修正志愿描述测试的依赖 mock，使其适配新的等待服务，保留原有全部业务断言。

## 已验证

- `node --test tests/loading.test.js tests/image-skeleton.test.js tests/volunteer-description.test.js`：10/10 通过。覆盖弹层重复关闭、遮罩与文案、页面归属与清理、退订、动画后台暂停、刷新防重及异常收尾、全量入口扫描、图片结束／失败和相册分页、志愿描述业务行为。
- `node --test tests/*.test.js`：83 项中 82 项通过。唯一失败为原有 `design-phase2.test.js` 的区块标题属性精确断言：现有组件包含 `meta`，预期列表未包含；本次未修改区块标题 JS 或该断言。
- 63 个小程序 JS 文件语法解析通过；40 个 WXML 文件通过开发者工具自带 wcc 编译；49 个 WXSS 文件通过自带 wcsc 编译。独立 wcsc 不直接解析项目根绝对导入，检查时仅在临时副本将导入改成等价相对路径，仓库导入未因此修改。
- 微信开发者工具 CLI 已检查当前版本 `--help`／`auto --help`，使用仓库根目录及自动化端口 9420；核对 appid 与 app.js 云环境一致。临时安装的官方 miniprogram-automator 位于系统临时目录，未加入项目依赖。
- 开发者工具 430px 模拟器中实际观察弹层和双方块；读取到 `rgb(3, 105, 215)`、`loading-square-lift`，跨帧 transform 不同。验证文案更新、mask 取消、关闭后 visible=false、首页滚动导航、只读刷新结束及跳转相册后弹层清理。

## 未覆盖与限制

- 未在 iOS／Android 真机验证透视、阴影、自定义下拉手势、键盘及原生控件遮挡；未执行 320／375px 的实际渲染验收或系统减少动效设置切换。静态媒体查询回退已实现，不将代码检查当作这些能力的真机结论。
- 未执行维修／志愿／值班写入或云部署。写入等待只验证公共展示、清理和已有业务回归，不制造真实业务记录。

# 个人页原生布局修复与验收

日期：2026-10-24。

## 问题与修复

用户真机截图显示个人身份卡姓名被拆行、角色被挤为窄列，卡片高度异常。此前只用浏览器映射预检，未覆盖微信原生按钮的默认尺寸，不能证明原生布局正确；本次以原生页面重新验证。

个人卡顶部将头像、姓名／角色与退出按钮放在一个 flex 行中，但原生退出按钮未显式设置迷你尺寸、宽度为 auto，中间文字区域可被压缩。修复文件仅 `miniprogram/pages/user/profile/index.wxml` 和 `index.wxss`：

- 退出按钮显式设置 `size="mini"`，局部选择器确定 88px 宽度、48px 最小高度和字体，避免平台默认样式挤占文字区域。
- 头像外层宽度与组件的大头像 Token 一致；姓名保留可换行与 `min-width:0` 的弹性布局。
- 角色标签限制最大宽度并纳入 padding，长文案可换行，不向相邻操作溢出。

沿用现有退出确认、部门切换、角色、路由和接口；没有变更 JS 业务逻辑，没有修改云资源、实际用户资料或登录存储。原有未提交修改保留。

# 维修详情操作按钮统一

按用户本次确认，维修列表／管理详情和个人待办维修详情的底部操作按钮使用同一套样式：实底白字、相同宽度与圆角，整组居中。认领使用品牌蓝、删除使用危险红，设置 EW、完成、确认完成与撤销任务使用黑底；这是本次明确指定的页面样式例外。

一个按钮居中；两个按钮以间隙中线居中；三个按钮以中间按钮居中。共用 flex 布局、等宽基准和固定间距，窄屏时等量收缩，最小点击高度为 48px。现有业务目前最多显示两个底部按钮，未新增第三个业务动作。

修改范围为两套页面的 WXML／WXSS 及共用 `miniprogram/styles/maintenance-actions.wxss`。显示条件、事件绑定、权限、任务状态及原有滚动／固定操作栏方式保持不变，弹窗按钮与卡片内协助受理人操作不在本次范围内。

验证采用 L0 调用链与样式审查、L1 定向差异检查；未运行全量测试或构建。尚未完成微信开发者工具／真机视觉验收，包括系统大字体、按钮加载态及底部安全区表现。

# 首页顶部毛玻璃调整

创建日期：2026-10-25。首页顶部样式已实现，官方静态编译通过，原生与真机视觉效果待验收。

## 实际改动

- 按用户截图指定的顶部区域，将首页导航改为 84% 不透明的乳白底和 24px 背景模糊；同时提供 `-webkit-backdrop-filter`。只模糊栏后内容，标志、标题保持清晰；滚动前后材质一致。
- 原首页 `--navbar-alpha`／`--navbar-blur` 未被公共样式消费，已替换为首页局部声明，同时覆盖公共滚动态选择器。其他页面导航不变。
- 保留状态栏、微信胶囊避让及首屏轮播占位；首屏栏后为浅色底，照片滚到栏后时才能观察到背景虚化。不支持背景滤镜时保留高不透明度白底。

## 依据与验证

读取设计索引、规范 01／06、设计 Token、前端重构计划及 ponytail／ui-ux-pro-max。本次为用户明确指定的首页局部材质调整；白色与深色标题沿用项目颜色基线。Skill 检索命中 Glassmorphism，仅采用背景模糊建议，不采用其低不透明度、反光与装饰边缘建议。

- 当前安装的微信官方 wcsc／wcc：48 个 WXSS、39 个 WXML 全量静态编译，退出码均为 0。
- 首页 JS `node --check`、本次涉及文件 `git diff --check` 通过。
- 首次单文件编译缺少根路径导入上下文，WXSS 失败、WXML 编译器异常退出；改为提供全量源文件后通过，未修改断言或检查范围。
- 编译产物保存在 Git 忽略目录 `项目管理/设计验收/2026-10-25-首页顶部毛玻璃/`。未进行原生模拟器与 iOS／Android 真机验证，尚不能确认各端背景滤镜支持及最终观感。

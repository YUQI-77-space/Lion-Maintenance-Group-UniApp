# 值班表布局与状态重做

创建日期：2026-10-24。范围：`miniprogram/pages/team/duty/roster/`。在既有未提交的设计改动上继续实施，未提交、部署或发布。

## 实际改动

- 页面分为周信息、本周排班、我的值班三个内容面；压缩重复的日期、编辑状态与使用说明，图例归入排班区域。
- 表格使用独立外框与连续单线网格，浅灰表头、白色固定时间轴、固定日期列宽；表头统一 60px、内容行统一 64px，状态变化不改变边框和行高。日期区域保留局部横滚。
- 可选为白底蓝字；预选为品牌蓝底白字和勾选；本人确认以浅绿、勾选与文字标明，区别于他人占用；休假与锁定分别沿用中性和警告语义。
- 修复预选、已有待确认、本人确认仍显示“可选”的展示问题，仅补充状态文字，保留既有状态值、权限、额度和提交逻辑。
- 个人列表将日期与时间分行，整合为一个核对确认入口。已有待确认记录不再显示实际上只操作本地数组的无效移除按钮，仍可通过原有确认链路提交。
- 按用户明确要求，个人时段卡片不使用左侧强调描边，四边均为统一细边框；以底色和文字区分状态。移除橙色渐变、红色圆形移除按钮及锁定脉冲动效。
- 清空、移除和确认使用原生按钮，点击热区不少于 48px；显式控制微信按钮宽度并将清空操作右对齐，底部保留安全区。

## 设计依据

采用知识库 Design 01 的品牌蓝及表面、间距、字号语义，02 的按钮和状态合同，03 的 P6 值班模板，04 的值班预选流程，05 的验证要求，以及 `design-tokens.json`。属于前端设计计划阶段 8 的局部视觉修订。

使用 `ponytail` 和项目 `ui-ux-pro-max` Skill。检索 `table cell selected contrast --domain ux -n 3`：采纳通用文字对比度建议；表格横滚建议来自 Web 条目，仅作为布局参考，实际使用原生 `scroll-view`，未引入网页框架、字体或依赖。用户关于禁用左侧强调描边的要求优先于样式建议。

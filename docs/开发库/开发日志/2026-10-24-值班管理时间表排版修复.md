# 值班管理时间表排版修复

创建日期：2026-10-24。范围：`miniprogram/pages/team/duty/manage/index.wxml`、`index.wxss`。保留既有未提交改动，未提交、部署或修改云资源。

## 问题与实际修改

旧表格使用 80rpx 表头、100rpx 内容行与带内边距的窄时间列；左右区域独立定义尺寸，状态格又增加不同粗细的边框，导致时间换行、文字挤出单元格和网格边界不一致。

- 时间列固定为 96px，日期列固定为 80px；时间范围保持单行。字号继续使用项目 Token。
- 左右共用 64px 表头高度、80px 内容行高和统一单线网格。状态及删除勾选不改变单元格尺寸；删除选择改为内部描边，移除缩放效果。
- 取消重复横向内缩，区块间隔增至 32rpx；添加日期区域横滑提示，保留固定时间轴。
- 表头、时间轴、可选、已排班和休假分别使用项目浅灰、白色、品牌蓝及语义色；移除表格旧渐变、深蓝外框和末尾相互覆盖的旧规则。
- 周信息卡采用四边均匀的中性细边框，没有左侧强调描边。顶部选中页签使用品牌浅底，移除旧阴影。
- 页面使用固定视口与剩余高度的 swiper，三个分页均使用原生纵向 scroll-view，避免放大表格后无法查看底部；删除模式仍为固定操作栏保留空间与安全区。

沿用 Design 01–06、设计 Token 与阶段 8 范围，使用本会话已读取的 `ponytail`、`ui-ux-pro-max`。补充检索 `table row spacing readability --domain ux -n 2`；采用移动端间距建议，Web 表格条目仅作横滚布局参考，没有引入 Web 框架或依赖。

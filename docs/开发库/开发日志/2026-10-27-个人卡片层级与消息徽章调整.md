# 个人卡片层级与消息徽章调整

日期：2026-10-27。

## 实际改动

阶段 1 个人页局部视觉精修补充，修改 `miniprogram/pages/user/profile/index.wxml`、`index.wxss`，同步更新设计规范 03 的个人页约定。

- 消息未读徽章改为 28px×28px 圆形、鲜红实底白字、600 字重，保留零值隐藏及超过 99 显示 `99+`。按用户明确要求，页面局部变量 `--profile-color-unread` 使用 `#DC2626`；危险操作仍沿用原有语义色，待办计数沿用既有外观。
- 退出登录移除可见文字，图标采用现有 40rpx 尺寸 Token，固定在卡片右上角；原生迷你按钮显式设为 48px×48px，保留无障碍名称、按下态与原退出确认。
- 个人身份卡最小高度 280rpx、上下内边距 48rpx，与下方列表间距 48rpx。头像和姓名／角色垂直居中，文字区预留按钮空间，长姓名可撑高卡片。

设计依据为 01 的留白、尺寸与文字规范、02 的入口行规范、03 的身份信息层级，以及用户本次对鲜红徽章、纯图标退出入口和加高卡片的明确要求。Skill 检索 `icon button accessible label --domain icons` 的首项为上下文图标无障碍建议，采用有名称的按钮与隐藏装饰图标，不引入推荐图标库。

没有修改 JS、接口、action、权限、请求次数、缓存、会话或数据写入路径。

## L1 局部验证

- 官方 `wcc.exe` 编译当前个人页 WXML，`wcsc.exe` 编译当前页 WXSS 及三个直接／间接导入样式，退出码均为 0。
- 两份页面源文件 `git diff --check` 通过。
- 基于实际页面 WXML/WXSS 的浏览器映射预检通过：320／375／430px 各覆盖短昵称、长昵称、`99+`，共 9 组修改后场景；另外保留 375px 相同脱敏数据的修改前映射截图。验证页面无横向溢出、身份卡高度至少为单行入口的 1.4 倍、姓名区避让退出按钮、按钮至少 48px×48px、退出无可见文字、徽章等宽高与 `99+` 显示。
- 按 sRGB 公式计算白字与 `#DC2626` 背景对比度为 4.829:1，达到 4.5:1。

初次映射预检因裁取页面片段后出现浏览器外边距折叠而失败，修正映射容器后通过；浏览器重启时另遇端口尚未就绪，确认监听后执行成功。这两项属于预检环境问题，没有为获得通过修改产品布局或删除断言。

源文件快照、同数据映射前后截图、布局报告、预检脚本和官方编译结果存放于已核实 Git 忽略的 `项目管理/设计验收/2026-10-27-个人卡片与消息徽章/`。映射头像为脱敏占位，浏览器预检不能替代微信原生控件与真机表现。

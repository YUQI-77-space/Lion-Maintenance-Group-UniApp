# 个人身份卡 SVG 柔雾背景

日期：2026-10-27。

## 已实现

按用户确认的方案①，为个人身份卡加入静态柔雾背景：左上淡蓝、右下淡紫、右上少量浅粉，中央透白。用户明确选择纯视觉装饰配色，此背景为个人卡的局部例外，不修改品牌主色与状态 Token。

- 新增随代码发布的 `miniprogram/assets/backgrounds/profile-mist.svg`，约 1.7KB，采用四层径向渐变形成柔和晕染，无外部引用、脚本、动画或模糊滤镜。
- 个人页 WXML 使用原生 `image` 加载 SVG，WXSS 将其独立定位到卡片底层，铺满并按圆角裁切；长姓名撑高卡片时背景同步伸展。
- 装饰图隐藏于读屏并禁用指针事件，内容层位于其上；保留白色卡片底面作为图片不可用时的回退。
- 头像、姓名、身份、退出按钮尺寸及业务 JS、计数徽章、接口与数据路径没有改变。同步更新设计规范 03 的背景约定。

设计依据为 01 的文字可读性、02 的轻量复用和本次用户确认的装饰方案。`ui-ux-pro-max` 查询 `text contrast background --domain ux` 命中通用文字对比度建议，使用实际渲染像素检查背景与内容对比度。未引入依赖。

## L1 局部验证

L0 确认影响仅为当前个人页的装饰资源与局部样式。采用现有官方编译和源码映射预检方式，完成以下范围后停止，没有扩大到全量或业务写入验证。

- 官方 `wcc.exe` 编译个人页 WXML，`wcsc.exe` 编译个人页 WXSS 及三个导入样式，退出码均为 0。
- 320／375／430px 各覆盖正常姓名、长姓名、背景隐藏后的白底回退，共 9 组修改后场景通过；保留 375px 同数据的修改前后截图和回退截图。
- 浏览器实际解码 SVG 并检查图片完整铺满卡片、正文中轴／顺序、无横向溢出、退出热区、退出与身份选择区的命中结果，均通过。背景 `pointer-events: none`。
- 对 SVG 渲染的 750×520 全部像素计算最低对比度：主文字色 `#182230` 至少 9.864:1，退出图标色 `#B83232` 至少 3.650:1；中央采样为白色。身份标签维持原有不透明浅蓝底与深蓝文字。
- `git diff --check` 通过。静态背景没有新增动态逻辑，不新增业务测试。

源码快照、编译产物、映射脚本、布局报告与脱敏截图位于 Git 忽略的 `项目管理/设计验收/2026-10-27-个人卡片柔雾背景/`。映射预检将本地 SVG 内容转为 data URL 供浏览器渲染与像素采样，产品代码仍引用随包发布的本地 SVG；头像使用脱敏占位。

## 限制与回退

未进行微信原生模拟器、iPhone／Android 真机上的 SVG 解码、层叠与点击验收，浏览器命中检查不作为原生交互通过证据。纯装饰 SVG 不可用时仍显示白色身份卡；背景隐藏检查只验证白底布局回退，不模拟微信图片解码错误。整体设计阶段保持待原生／真机验收状态。

回退仅移除新增背景图片节点、局部背景层样式与 SVG 文件，保留此前徽章复用和身份卡居中改动。

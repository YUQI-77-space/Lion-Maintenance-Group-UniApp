# 报修表单选择器排版修复

创建日期：2026-10-24。范围：报修页 WXML、WXSS；保留工作区已有改动。

## 原因与修改

公共 `data-pages.wxss` 的 `.mg-data-page .picker-value` 为输入控件设置边框、圆角和 48px 最小高度。报修页的日期、时间和系统版本使用同名类展示文本，因而出现文字外套输入框、预约行被撑高的问题。

- 报修页三处显示值统一改为 `repair-picker-text`，同步修改占位态选择器，隔离公共控件规则；公共样式及其他页面保持原状。
- 选择行最小高度为 48px；预约行使用 16rpx 纵向内边距，标签、值和箭头居中，日期时间保持单行。
- 分隔线改为匹配相邻 `picker` 的行。原 `:last-child` 实际匹配每个 picker 内的唯一子元素，导致两行分隔线都被移除。
- 不修改页面 JS、预约校验、数据、云函数及提交行为。

依据 Design 01、02、05、06、设计 Token 和前端重构计划阶段 6；使用 ponytail、ui-ux-pro-max。针对性检索中，`form control size alignment` 未提供直接匹配的布局建议，进一步检索 `touch target size`，采用移动端触控建议并按项目至少 48px 的规则实现。

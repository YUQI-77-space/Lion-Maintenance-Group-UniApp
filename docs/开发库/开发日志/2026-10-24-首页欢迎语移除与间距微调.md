# 首页欢迎语移除与间距微调

## 实际改动

- 移除快捷入口下方的欢迎语整行（问候、姓名、日期和角色），同时清理专用数据、生成方法及样式。
- Banner 与四个快捷按钮之间的间距由 24rpx 增至 32rpx；快捷按钮下方间距同步增至 32rpx。
- 间距依据知识库 Design/01 与 design-tokens.json 的区块间距；保留现有照片、快捷入口顺序和权限。

## 验证与限制

- 首页 JavaScript 语法检查通过。
- design-phase1、design-remaining 两组现有测试共 27 项通过。
- 静态检查确认欢迎行及专用生成逻辑已移除，目标间距为 32rpx。
- 未执行开发者工具或真机视觉验收；实际设备上的视觉效果待确认。

## 后续修正：统一首页全部板块间距

用户截图反馈快捷入口上下可见间距不一致。上次仅确认声明值，未验证实际布局，不能据此认定视觉一致。

- 首页改为纵向 flex 容器，由 gap: var(--mg-space-4) 统一生成全部相邻板块的 32rpx 间距；所有一级板块外边距归零，Banner 顶部保留独立的 24rpx 导航留白。
- 清理值班卡片历史负外边距和其他分散的板块 margin；条件隐藏值班或 Banner 时仍由容器负责相邻可见板块间距。
- 团队风采图片轨道改为块级 flex 并移除底部 6rpx 留白；团队荣誉轨道改为块级 flex，高度与图片的 240rpx 对齐，移除行内基线及轨道额外高度造成的留白。
- 已通读首页七类一级板块及公共标题样式；保持板块内部的信息层级、按钮热区和图片间距。
- 现有三组设计回归测试 33 项通过；官方 wcsc 编译通过。
- CLI 帮助已核对，auto 连接因 IDE 服务端口关闭失败。未改动安全设置，未取得本轮模拟器尺寸或截图证据；实际设备视觉一致性仍待复核。

# 志愿活动语录移除

创建日期：2026-10-25。

## 实际改动

- 移除志愿活动列表中的励志语录库、随机选取逻辑、卡片语录展示及专用样式。
- 已结束活动不再渲染底部操作栏，避免删除语录后留下空白区域；保留活动信息和状态。
- 保留既有筛选、详情导航、报名与取消报名逻辑。

## 设计依据

遵循[信息架构与页面规范](../../知识库/Design/03-信息架构与页面规范.md)第 7 节的文字克制要求，删除装饰性口号，聚焦查找与管理活动。Skill 检索未提供适用于本次文案删除的直接建议，采用项目规范。

## 验证与限制

- Node.js 语法检查通过。
- 使用 Node.js VM 加载真实页面定义，检查四种活动状态映射、满员与招募字段、时间格式化、原始数据不被修改，均通过；确认不再生成语录字段。
- 静态检查确认已结束活动底栏条件、报名和详情事件绑定保留；志愿活动目录无语录字段与相关文案残留。
- 目标目录 Git 差异空白检查通过。
- 未进行微信开发者工具渲染或实机交互验收；未部署云函数。

# 组员管理页头精简

创建日期：2026-10-25。对应前端改造计划阶段 5 的成员列表展示调整。

## 实际改动

- 删除正文中重复的「组员管理」标题和「查看组内成员，管理资料与权限」说明，保留原生导航栏标题。
- 将成员数量及加载提示移至部门、角色筛选同行的最右侧，保留原有计数数据来源。
- 搜索框采用包含边框的 48px 高度，输入框随容器高度调整，收紧头部上下留白，为列表释放空间。
- 用 WXSS 边框绘制下箭头，在固定图标区域内对齐；箭头继承筛选状态颜色。筛选文字过长时省略，避免挤压右侧计数；清空及重置按钮保留 48px 热区。

仅修改成员管理页 WXML、WXSS，保留工作区原有字体 Token 调整。未修改搜索、筛选、权限、分页、后端接口或数据。

## 设计依据

遵循 [组件规范](../../知识库/Design/02-组件规范.md) 的轻量双维度筛选、搜索与清空约定，以及 [设计 Token](../../知识库/Design/design-tokens.json) 的文字层级、语义颜色和最小点击热区要求。使用项目 ui-ux-pro-max 检索移动端点击目标及间距建议，并按小程序适配规则采用 48px 热区、8px 筛选间距。没有新增依赖。

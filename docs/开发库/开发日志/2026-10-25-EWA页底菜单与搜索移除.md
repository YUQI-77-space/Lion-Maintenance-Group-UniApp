# EWA 页底菜单与搜索移除

创建日期：2026-10-25。接续[领奖台调整](2026-10-25-EWA领奖台与轻量操作调整.md)，记录本轮实际改动。

同日追加调整：按用户最新位置要求，顶部改为左侧加载计数、正中“成员排名”、右侧“数据操作”的三段布局；左右两列等宽，标题按页面内容中线居中。菜单迁到顶部后向下展开，“查看统计”仍位于页底右侧。该追加修改只涉及 WXML／WXSS，41 个 WXML、50 个 WXSS 官方静态编译通过；下述 63 组布局与 24 项回归为追加修改前的记录，不作为新布局的真机验收证据。

同日原生截图反馈修正：用户截图显示“数据操作”文字高于人数和标题。顶部三列统一至少 48px 高并垂直居中，人数与标题采用相同文字行盒；数据操作显式覆盖原生 mini 按钮行盒，使用 48px 行高及零内边距，避免只依赖按钮匿名文字的 flex 居中。保留左右等宽及标题水平居中。官方静态编译通过，尚未取得修改后的微信原生截图，不以此前浏览器映射通过声称已完成原生效果验收。

## 已实现

- 移除“工作量排名”标题、搜索框及加权公式说明；顶部只保留“成员排名”和读取计数。
- 删除页面搜索状态、搜索图标依赖、防抖、搜索处理方法和请求搜索参数；直接使用 `users` 渲染，保留排名读取、缓存与展开分页。
- 页底右侧并排显示“数据操作”和“查看统计”。数据操作菜单包含“刷新汇总”“导出 Excel”，在按钮上方向上展开，避免超出底部；选择后、点击外部、页面隐藏或下拉刷新时收起。
- 菜单仅对有权用户响应；刷新或导出期间显示进度文字并禁用入口，刷新沿用原有确认、写入锁与无自动重试策略。下拉继续只读取排名。
- 领奖台继续使用透明外层，保留高低台阶和成员调整入口。

## 依据与验证

样式沿用[设计语言](../../知识库/Design/01-设计语言与视觉规范.md)、[组件规范](../../知识库/Design/02-组件规范.md)及 Token；浮层与点击拦截层的层级采用规范中的 1000／900，菜单项最小热区 48px。

- 微信官方 `wcc` / `wcsc` 静态编译：41 个 WXML、50 个 WXSS 成功，三个关联 JS 语法检查通过。
- `node --test tests/design-remaining.test.js`：24 项通过。原搜索排队测试按功能移除改为刷新排队与缓存正确性测试，保留旧响应不得覆盖最新结果的检查；新增菜单关闭后分发、忙碌及无权限不执行的检查。
- 320／375／430px，共 63 组源码映射布局检查，无横向溢出或小于 48px 的按钮。去除失效搜索样本，新增菜单展开、空数据展开菜单、忙碌、无权限、仅一／两人和缺失分数。
- 375px 菜单展开样本目视检查：顶部冗余内容已移除，领奖台外层无白底，菜单与统计入口位于页面内容底部靠右。

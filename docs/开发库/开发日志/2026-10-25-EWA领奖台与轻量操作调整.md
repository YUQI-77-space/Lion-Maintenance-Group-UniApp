# EWA 领奖台与轻量操作调整

创建日期：2026-10-25。范围：排名页 WXML 与 EWA 共用外观层。接续[二次重构记录](2026-10-25-EWA排名与统计界面二次重构.md)，以本轮实际实现为准。

## 实际改动

- 标题右侧并排显示“导出 Excel”“查看统计”文字按钮。使用原生 `size="mini"`，显式收紧宽度、清除底色与边框，保留最小 48px 点击热区、按下态及导出禁用态。
- 前三名独立展示为第二名／第一名／第三名领奖台。冠军居中、头像与分数更突出，台阶分三级高度；普通列表从第四名开始，保留原始序号与点击调整能力。
- 同日按追加反馈移除领奖台外层白色背景与圆角，头像、姓名和台阶直接呈现在页面背景上；仅删除两条外层样式，静态检查确认台阶自身样式保留，未重复运行此前回归或补充真机验证。
- 搜索结果使用普通列表，不将搜索结果误作全局前三名；不足三人时只显示真实成员，不补占位或伪造名次。
- 移除页尾“数据管理”和两个整行按钮，并删除对应闲置样式。排名标题旁的小刷新按钮调用原有 `updateAllEW`，保留确认提示、写入锁和失败反馈；下拉刷新继续只读取排名。
- 无 JS、接口、云函数、数据库、权限或计算口径变更；导出与成员调整沿用原有调用链。

## 设计依据

沿用[设计语言](../../知识库/Design/01-设计语言与视觉规范.md)、[组件规范](../../知识库/Design/02-组件规范.md)、[EWA 交互合同](../../知识库/Design/04-关键交互流程.md)及统一 Token。领奖台为本排名场景的特殊布局，使用品牌蓝、同源浅底与文字名次表达层级，不增加另一套金银铜配色、图片或依赖。

UI/UX Skill 检索 `touch target size` 的移动端结果仅作辅助；实际热区按项目要求至少 48px，而非照搬网页或其他平台单位。

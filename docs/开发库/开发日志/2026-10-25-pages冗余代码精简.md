## 设计与交互依据

字数计数沿用 [组件规范](../../知识库/Design/02-组件规范.md)、[关键交互流程](../../知识库/Design/04-关键交互流程.md) 及 [Skill 适配规则](../../知识库/Design/06-Skill使用规范.md)，不调整视觉 Token 或页面布局。

textarea 的 `bindinput` 同步更新 `formData.description` 和 `descriptionLength`，保留编辑回填和校验失败时的输入。原 `IntersectionObserver` 监听元素可见性，不能反映持续输入，现已移除。沿用现有 JavaScript 字符串长度口径。

已读取 ponytail 与项目 ui-ux-pro-max Skill。两次定向 UX 检索未获得字数计数的准确匹配，不将返回的输入类型、按下反馈或提交反馈建议当作本次实现依据；实现以项目规范和原生输入事件为准。

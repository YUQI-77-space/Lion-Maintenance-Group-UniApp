# 首页布局回归修复与原生验收

日期：2026-10-24。

## 范围与原因

用户反馈统一设计后首页视觉退化：Banner 被移至报修进度之后且关闭自动播放，原生按钮偏离行末，团队荣誉停止循环。此次以恢复首页照片展示特色为目标，不扩展到全站重新设计。

实际改动：`pages/home/index.{wxml,wxss,js}`、`components/section-header/index.{wxml,wxss}`、`tests/design-remaining.test.js`；同步修订设计规范 01、03 与实施计划阶段 4。工作区原有启动页改动未由本次修改。

## 已实现

- Banner 恢复至导航下方，3.5 秒自动循环，保留可见暂停／播放控制；快捷入口紧随其后，问候压缩为轻量行。
- “查看全部”和区块“更多”贴齐内容右侧。使用原生迷你按钮并显式限定宽度；局部选择器覆盖平台迷你按钮的默认 display、行高与字重，箭头保持水平居中。
- 荣誉恢复双组循环，显式计算单组宽度和末尾间距，平移 50% 后回到相同接缝；图片宽度按实际 240rpx 高度计算，取消运动图片懒加载造成的空白风险。
- 首页离开时暂停动画，返回保留手动暂停状态；修复页面重建后仅依据 App 加载标记而不恢复当前页荣誉数据的问题。
- 用户暂停、角色判断、原路由及事件保留；未修改云函数 action、参数、权限、数据库或写请求策略。

## 验证

- 开发者工具 Stable 2.02.2608080，项目本地配置基础库 3.17.2，使用原生 WebView 模拟器与当前已登录成员身份；首页报修为空、值班为空，展示现有云图片。
- 官方 wcc 编译 41 个 WXML、wcsc 编译 49 个 WXSS，退出码均为 0。Node 27 项相关检查通过，含两项新增首页轮播生命周期、宽度和重建加载检查。
- CLI --help 和 auto --help 已检查；CLI auto 因工具服务端口关闭不能连接。依据用户本次授权使用 Computer Use 完成截图与必要的滚动／点击，不修改安全设置。
- 已观察 Banner 自动更换照片、区块操作靠右、荣誉照片连续向左运动。具体尺寸及暂停操作结果在最终记录中补充。

截图及编译结果保存在已通过 git check-ignore 核实的本地目录 `项目管理/设计验收/2026-10-24-首页视觉回归/`，含当前身份信息，不提交图片。知识库保存布局约束，本记录保存实施结果。
